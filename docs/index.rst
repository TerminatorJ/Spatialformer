Welcome to the documentation for SpatialFormer, a Python package for single-cell spatial omic data analysis using pretrained foundation models. This package is based on the work of Spatialformer (`GitHub <https://github.com/TerminatorJ/Spatialformer/tree/master>`_, `preprint <>`_) and provides a set of functions for data preprocessing, visualization, and model evaluation.
